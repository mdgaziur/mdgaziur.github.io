SUST OJ

Online judge for SUST. Uses Svelte and Gin for backend and frontend. RabbitMQ is used as a message broker between the judge server and the backend server. The judge server is implemented using Rust. It utilizes ssandbox sandboxing library to execute untrusted code in a secure environment. Deployment strategy makes use of Docker, Kubernetes and Terraform.

ssandbox

Container based sandbox made using CGroup, Namespace, and Seccomp. Can track execution time, memory usage, capture STD(OUT/ERR), set STDIN and enforce resource limits. It can also manage mountpoints inside the container. Available as a Rust library and CLI.
